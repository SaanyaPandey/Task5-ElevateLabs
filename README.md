<h1>AI Detective Game</h1>

<p>
AI Detective Game is a frontend-only interactive detective game built using HTML, CSS, and JavaScript.
Players investigate different mystery cases by collecting clues, analyzing evidence, questioning suspects, and making the final accusation to solve each case.
</p>

<h2>Features</h2>

<ul>
  <li>Responsive user interface</li>
  <li>Multiple detective cases</li>
  <li>Evidence collection system</li>
  <li>Suspect profiles</li>
  <li>Interactive investigation flow</li>
  <li>Final accusation and result screen</li>
  <li>Smooth animations and modern UI</li>
  <li>Dark/Light theme support</li>
</ul>

<h2>Technologies Used</h2>

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript (Vanilla JS)</li>
</ul>

<h2>How to Run</h2>

<ol>
  <li>Download or clone this repository.</li>
  <li>Open the project folder.</li>
  <li>Open <code>index.html</code> in any modern web browser.</li>
</ol>
